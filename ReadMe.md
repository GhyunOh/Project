# Project Repository

This repository is a collection of multiple projects across data analysis, machine learning, computer vision, and security.  
Each folder represents a separate project with its own focus, dataset, and methodology.  
Below is a brief introduction to each project.

---

## 📂 Projects Overview

### 1. Baron
- Focused on system security and vulnerability analysis.  
- Includes practical demonstrations and write-ups on exploiting or mitigating well-known vulnerabilities.  

### 2. Crime
- A crime data analysis project using Python.  
- Analyzes crime rates by type, age, gender, and year (2012–2019).  
- Provides visualizations and insights into juvenile crime patterns and motivations.  

### 3. Computer Vision for Automation
- Applied computer vision techniques to build an automation pipeline.  
- Crops specific window regions to minimize memory usage.  
- Integrates with Windows API (win32), keyboard, and mouse controls to perform automated actions when objects are detected.  

### 4. License Plate Number Recognition
- A computer vision project.  
- Implements license plate detection and recognition using machine learning techniques.  
- Applies image preprocessing and deep learning models to extract and classify plate numbers.  

### 5. R_Project
- Early works and experiments using R programming language.  
- Includes exploratory data analysis and statistical modeling.  

### 6. Weather Prediction
- A weather forecasting model built with machine learning.  
- Uses Korean Meteorological Administration data (2010–2020).  
- Simplifies forecasts into binary classification (Clear/Rain) and achieves **90%+ accuracy** with Random Forest.  

### 7. Telescope Benchmark Prototype
- A prototype project to benchmark telescope-related data processing.  
- Focuses on handling large data logs and evaluating computational performance.  

### 8. Telescope Log
- Structured logging and analysis for telescope observation data.  
- Designed for better management, retrieval, and research workflows.  

### 9. Image Inpainting (AI Challenge)
- Hackathon project submitted to **NIPA AI Online Competition (2022)**.  
- Focused on satellite image inpainting, filling in sensitive regions with AI models.  
- Applied **diffusion models** and **transformer-based fine-tuning** on pretrained networks.  
- Ranked **7th out of 43 teams**, with less than 1 PSNR difference from the 1st place team.  

### 10. DeepLearning Hub
- A beginner-friendly tutorial website for learning deep learning.  
- Covers step-by-step setup (Python, Jupyter, CUDA/cuDNN, PyTorch, YOLOv5).  
- Guides data preparation and training a custom YOLO model.  
- Uses Google Colab with free GPU resources for accessibility.  
- Accessible here: [DeepLearning Hub](https://deeplearning-hub.github.io/)
