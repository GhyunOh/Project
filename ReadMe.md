# Project Repository

This repository is a collection of multiple projects across data analysis, machine learning, and security.  
Each folder represents a separate project with its own focus, dataset, and methodology.  
Below is a brief introduction to each project.

---

## 📂 Projects Overview

### 1. Baron
- Focused on **system security and vulnerability analysis**.  
- Includes practical demonstrations and write-ups on exploiting or mitigating well-known vulnerabilities.  

### 2. Crime
- A **crime data analysis project** using Python.  
- Analyzes crime rates by type, age, gender, and year (2012–2019).  
- Provides visualizations and insights into **juvenile crime patterns and motivations**.  

### 3. License Plate Number Recognition
- A **computer vision project**.  
- Implements license plate detection and recognition using machine learning techniques.  
- Applies image preprocessing and deep learning models to extract and classify plate numbers.  

### 4. R_Project
- Early works and experiments using **R programming language**.  
- Includes exploratory data analysis and statistical modeling.  

### 5. Weather Prediction
- A **weather forecasting model** built with machine learning.  
- Uses Korean Meteorological Administration data (2010–2020).  
- Simplifies forecasts into binary classification (Clear/Rain) and achieves **90%+ accuracy with Random Forest**.  

### 6. Telescope Benchmark Prototype
- A prototype project to **benchmark telescope-related data processing**.  
- Focuses on handling large data logs and evaluating computational performance.
