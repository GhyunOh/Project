# Deep Learning Hub (DLHub)

**Deep Learning Hub (DLHub)** is a tutorial website made **for beginners** who want to learn deep learning step by step.  

---

## 📖 Overview
Deep learning is powerful but often difficult for first-time users.  
DLHub was created to **make the first steps easier**, especially for **undergraduate students and beginners** who have no prior experience.

---

## 🚀 Learning Steps

1. **Setting Up an Environment**  
   - Guides for installing Python, Anaconda, Jupyter, CUDA, cuDNN, PyTorch, LabelImg, and YOLOv5.  

2. **Data Preparation**  
   - Learn how to collect, label, and prepare datasets for deep learning.  

3. **Data Recognition with Deep Learning**  
   - Build a simple object detection model using **Google Colab** (free GPU support).  

---

## 🎯 Why DLHub?
- Designed **for first-time users**  
- Uses free and accessible tools (Google Colab)  
- Simple, step-by-step tutorials  
- Helps students start deep learning projects quickly  

---

## 🛠️ Technologies Used
- Python, Jupyter Notebook  
- PyTorch  
- YOLOv5  
- CUDA, cuDNN  
- LabelImg  
- Google Colab
